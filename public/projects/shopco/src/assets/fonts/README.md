# Satoshi

Weights 400, 500 and 700, normal style. Obtained from the official Fontshare CSS API:
https://api.fontshare.com/v2/css?f[]=satoshi@400,500,700&display=swap

Font and license information: https://www.fontshare.com/fonts/satoshi
License: https://www.fontshare.com/licenses/itf-ffl

Integral CF font binaries are not included. Static headings and SHOP.CO logo in ../type/ are vector outlines exported from the user-provided original Figma file. They preserve the desktop and mobile layouts and have accessible alternative text in the HTML.
